# Clothesline for Windows — 首个候选版

[English](README.en.md) · 简体中文

原生 WPF / .NET 10 LTS，目标 Windows 10 1809+ / Windows 11 x64（Intel、AMD）。使用独立晾衣绳图标，安装包携带仓库完整 MIT 许可。

默认监听系统已知 Downloads 文件夹；可同时添加多个文件夹。完成检测要求至少两次稳定扫描、两秒静默，并过滤常见下载临时后缀。支持顶层文件/目录、拖入挂载、真实文件拖出（可按住 Ctrl 移动原文件）、打开/图片缩略图、固定、保留扩展名重命名、悬停身份、最近文件搜索、自动隐藏/一直显示、中英文托盘与卡片菜单、**设置窗口（含功能开关、监控文件夹增删、剪贴板与文字识别引擎）**、手动检查 Windows 更新、开机启动开关及关于。

剪贴板图片/文字挂载**默认开启**，可随时在托盘菜单关闭；只接开启后新复制内容，去重并抑制自身复制。文字支持编辑，图片/文字可另存为；会话副本不进入持久最近记录，退出只清理应用自建会话目录。异常退出可能遗留临时副本。

指针离开后晾衣绳有 **1.8 秒**宽限期再自动收回；全屏播放视频或游戏时自动隐身。**Ctrl+Alt+↑** 随时切换"一直显示 / 自动隐藏"。

图片卡片右键可**提取文字（OCR）**。默认使用随程序附带的 **PP-OCRv6**（Tiny 档，无需联网），识别率明显优于系统自带引擎；也可在「设置 → 文字识别」里换回 Windows 自带识别（Windows.Media.Ocr）或下载更高档模型。两种方式都不联网、不上传图片。识别结果复制到剪贴板并弹出窗口供核对。

首版仅主屏工作区域，不递归监听目录；不包含 macOS Quick Look、系统分享、废纸篓删除与多屏跟随。取下/清空只改展示状态，原文件不变；重命名只有明确操作后才执行且拒绝覆盖。文件夹不递归统计大小，链接/隐藏/系统文件不自动挂载。

设置保存在 `%LocalAppData%\Clothesline\settings.json`，不存文件内容。仅点击检查更新时访问本仓库 GitHub Releases，不上传文件或剪贴板；Windows 使用 `windows-v` 标签，避免向 macOS 用户提示 Windows 安装包。开机启动只在显式选择时写入当前用户 Run 项，安装不自动开启。默认安装到当前用户的 Programs，无需管理员权限。卸载仅移除程序和指向本次安装的启动项，保留设置与用户源文件。

## 安装和使用

1. 安装 Setup.exe，或将便携 ZIP 完整解压到固定位置再运行 Clothesline.exe；不要只拷贝 EXE。
2. 启动后在任务栏通知区域（可能在折叠图标中）找到晾衣绳图标。
3. 鼠标移至主屏工作区域顶部展开；默认下载文件稳定约两秒后挂上。也可从托盘选择一直显示。
4. 从资源管理器拖入文件/文件夹；从卡片拖出到支持文件的窗口。右键操作卡片，滚轮查看溢出项目。
5. 语言 / Language 可切换中文、English。开机启动由用户自行开启。

## 操作速查

| 操作 | 结果 |
|---|---|
| 鼠标移到屏幕顶部 | 晾衣绳滑下，指针离开 1.8 秒后自动收回 |
| **Ctrl+Alt+↑** | 切换一直显示 / 自动隐藏 |
| 单击卡片 | 复制（图片复制为位图），卡片上浮现"已复制" |
| 双击卡片 | 用默认应用打开 |
| 拖动卡片 | 拖出副本，原文件保留 |
| **按住 Ctrl 拖动** | 移动原文件：拖放成功后原文件送入回收站，卡片离开晾衣绳 |
| 卡片左上角 ● / ○ | 固定 / 取消固定 |
| 卡片右上角 × | 取下，只隐藏卡片，原文件不动 |
| 右键卡片 | 打开、复制、复制图片、复制文字、**提取文字（OCR）**、编辑（系统默认编辑器）、另存为、在资源管理器中显示、重命名、固定、取下（保留原文件）、**取下（删除原文件）** |
| 全屏播放视频/游戏 | 晾衣绳自动隐身；此时若正在拖动文件，仍会滑出以便放下 |

按住 Ctrl 拖动会写入 `CFSTR_PREFERREDDROPEFFECT` 请求移动，但**资源管理器并不会对来自其他程序的 CF_HDROP 执行移动**。因此晾衣绳在拖放成功后自行收尾：目标若真的移动了，原文件已消失，直接取下卡片；否则把原文件送入回收站再取下。选回收站而不是直接删除，是因为晾衣绳看不到目标把副本放在哪里，也就无法确认副本真的落盘——回收站让这唯一可能出错的情况仍可恢复。

## 提取文字（OCR）

两个引擎，在「设置 → 文字识别」里切换。图片都不出本机。

### PP-OCRv6（推荐，识别率明显更高）

随程序附带 Tiny 档，首次使用自动解包，**不需要联网**。Small（30 MB）与 Medium（132 MB）在设置窗口里点击下载，从 ModelScope 获取，落盘前按 PaddlePaddle 公布的 SHA256 校验。

| 档位 | 体积 | 标签数 | 适用 |
|---|---|---|---|
| Tiny | 6 MB | 6,904 | 截图、印刷体，日常足够 |
| Small | 31 MB | 18,708 | 生僻字、小字号 |
| Medium | 139 MB | 18,708 | 扫描件、复杂版式 |

实测同一张图：Windows 自带引擎把 "Clothesline" 读成 "CIothesIine"，PP-OCRv6 三档全部识别正确。档位越高越准也越慢，Tiny 在普通截图上约半秒。

### Windows 自带识别

调用 `Windows.Media.Ocr`，零下载。

- **语言包决定能不能用。** Windows 只随系统安装用户勾选过的识别语言。设置窗口里列的是这台机器真实可用的语言；一项都没有时会明确写出"未安装 OCR 语言包"，并引导到 Windows 语言设置。
- **装中文包：** 设置 → 时间和语言 → 语言和区域 → 添加"中文（简体）"→ 语言选项里勾选**光学字符识别**。装好后重启晾衣绳即可，无需改配置。
- 中文引擎也能读英文和数字，反过来不行，所以"自动选择"优先用中文（若已安装）。
- 超过引擎上限（`MaxImageDimension`，实测 10000 px）的图片会先等比缩小再识别。

无论哪个引擎，手写体、艺术字、低对比度截图、极小字号都可能识别不准——结果窗口就是用来核对的。

## 设置

托盘「设置…」打开设置窗口，五个分区：常规、功能开关、监控文件夹、剪贴板、文字识别。

**监控文件夹**可逐个添加与移除。移除只停止监控，磁盘上的文件夹不会被删除。

**功能开关**里每一项都能单独关闭，关掉的功能不再占用快捷键，也不会对文件做任何事：

| 开关 | 关闭后的效果 |
|---|---|
| 拖到晾衣绳上时挂起 | 拖放穿透给下方窗口 |
| 按住 Ctrl 拖动为移动 | Ctrl+拖动只复制，原文件不动 |
| 单击卡片即复制 | 单击不做任何事 |
| 卡片上的固定 / 取下按钮 | 卡片更干净，功能仍在右键菜单 |
| 全屏时自动隐身 | 全屏时不再收起 |
| Ctrl+Alt+↑ 显示 / 隐藏 | 组合键让给其他程序 |
| 自动收回延时 | 0.8 / 1.8 / 3 / 5 秒可选 |

## 资源管理器集成

安装程序默认同时注册两处，卸载时一并清除：

- **右键菜单「挂到晾衣绳」**——经典 shell 动词，写在 `HKCU`，不需要管理员权限，也不安装任何 COM 扩展 DLL。Windows 11 下位于「显示更多选项」，Windows 10 直接显示。
- **「发送到 → Clothesline」**——SendTo 是快捷方式目录，在 Windows 11 的主右键菜单里直接可见，比上一项更快。

也可以不装程序、单独执行脚本：

```powershell
# 安装（需先构建 Windows 版，或用 -ExePath 指定 Clothesline.exe）
./scripts/windows-context-menu.ps1

# 卸载
./scripts/windows-context-menu.ps1 -Uninstall
```

多选文件时资源管理器会对每个文件各启动一次进程，这些进程会因单实例限制立刻退出；它们把路径留在 `%LocalAppData%\Clothesline\pending`，正在运行的实例在下一次扫描时把全部文件一起挂上。

在 Windows 安装 .NET 10 LTS SDK 和 Inno Setup 6 或 7，运行：

```powershell
# 只做自包含发布 + 安装程序（最快拿到可用产物）
./scripts/build-windows-installer.ps1 -Iscc "C:\Program Files (x86)\Inno Setup 7\ISCC.exe"

# 完整流程：核心测试、自检、发布、便携包、校验和
./scripts/build-windows.ps1
```

自动运行核心测试、self-contained 发布、WPF 构造/文件拖放数据 smoke test、安装/卸载与源文件保留测试，输出 `build/windows/dist` 下的 Setup.exe、便携 ZIP 和 SHA256SUMS.txt。用户无需预装 .NET。`.github/workflows/windows.yml` 在 Windows runner 执行同样流程。

Windows runner [38701416790](https://github.com/zhongguozhang/Clothesline/actions/runs/38701416790) 已通过最终编译、核心/真实 watcher、WPF 构造与文件拖放数据、图片文件锁、安装/安装后测试与卸载及源文件保留验证；这些自动测试不能视为完整 Windows 桌面操作验收。安装程序暂未 Authenticode 签名，Windows 可能显示未知发布者。
